# Mac / iPhone 手工验收清单

以下项目**尚未在模拟器或真机执行**。请在实际构建后逐项记录系统版本、设备、结果和截图。不要为了验收提交订单或支付。

## 安装与界面

- [ ] Xcode 能打开工程，Bundle Identifier 可修改，模拟器 Debug build 成功
- [ ] Swift Package 的 17 项 XCTest 通过；确认不是只有“0 tests”
- [ ] iPhone 小屏/常规屏、浅色/深色模式、最大辅助字体下无按钮遮挡，键盘可以收起
- [ ] VoiceOver 可以读出计划、倒计时、错误清单和操作名称
- [ ] 退出重启后计划仍在；核对内容不持久保留

## 计划编辑

- [ ] 初次打开没有虚构型号、价格或官方发布日期；倒计时未启用
- [ ] 输入完整配置与预算，保存后展示正确；取消编辑不保存
- [ ] 空值、0、负数、超长金额、1e3、NaN、货币符号、逗号金额、三位小数均不能通过核对
- [ ] 修改日期或时区会取消“已确认时间”勾选；重新确认前不能安排提醒
- [ ] 从上海换到洛杉矶只改变显示钟点，保持同一绝对时刻；跨夏令时检查显示
- [ ] 保存任意计划改动取消旧提醒；原样保存不取消

## 倒计时

- [ ] 设置 2 分钟后的测试时间，前台倒计时归零后不出现负数
- [ ] 切后台 1 分钟再回来，倒计时按实际当前时间恢复
- [ ] 到达目标时仅提示“到你设置的时间”，不自动打开浏览器或操作页面
- [ ] 调整系统时钟后能解释倒计时变化；App 未宣称已联网校时

## 本地通知

- [ ] 首次点设置出现系统通知授权；拒绝后有明确提示和设置入口
- [ ] 已授权时分别测目标时刻/提前 5 分钟/提前 15 分钟的单次提醒
- [ ] 提前量已过去时设置按钮禁用；把页面停留到过期时，状态更新
- [ ] 系统权限弹窗长时间停留导致触发时刻过去时，不立即补发过去的提醒
- [ ] 快速重复设置只保留一个 pending request；完成按钮在处理中禁用
- [ ] 取消后不再有本 App 的待提醒；计划变更不能被先前设置操作覆盖
- [ ] 手机变换时区后，提醒仍对准同一绝对目标瞬时
- [ ] 检查后台、锁屏、前台、专注模式、静音状态；明确哪些情况系统不显示横幅或延迟

## 人工核对

使用离线示例“示例型号 A / 示例颜色 / 256GB”，不需打开实际购买页：

- [ ] 预算 10000，总额 10000.00、数量 1 且三项确认齐全 → 填写值一致
- [ ] 总额 10000.01 → 超预算警告
- [ ] 缺总额、缺数量、缺任一配置、预算为空 → 不给出一致结果
- [ ] 数量 2、01、1.0，以及颜色/容量/型号不同 → 不给出一致结果
- [ ] 未确认币种/费用完整/一次性付款中的任意项 → 不给出一致结果
- [ ] 修改任意输入或计划后，旧结果立即隐藏
- [ ] 切至浏览器/锁屏/控制中心使 App 非活跃后，结果隐藏并清除确认勾选
- [ ] 核对按钮不会打开网页、加购、创建订单或付款

## 官网与隐私

- [ ] “打开 iPhone 官网”使用系统默认浏览器，网址起点为 https://www.apple.com.cn/iphone/
- [ ] 商店首页备用入口起点为 https://www.apple.com.cn/store
- [ ] 返回 App 后界面正常，不重复打开浏览器；无网/打不开时用户可手动访问
- [ ] 浏览器内后续跳转、登录、验证码及付款均由用户操作，App 没有控制权
- [ ] App 不请求相机、麦克风、定位或通讯录权限，没有网络统计 SDK

- [ ] 真机运行和通知权限/投递行为验证；模拟器成功不能代替此项
- [ ] 若需分发，确认开发者资格及当前 SDK 要求，Archive / Validate / Export 在实际 Xcode 成功
